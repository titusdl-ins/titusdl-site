What's live today

A CRM built for how insurance agents actually work

Not a generic CRM with insurance fields bolted on. Every screen assumes you're tracking policies, families, and deadlines that matter for compliance — because that's what it was built to do.

8 policy types, one view

Life, Medicare, health, annuity, cancer, long-term care, business retirement plans, and group health — each with the fields that product actually needs.

Family & joint policies

Link family members and joint-owned policies so a household shows up as one connected picture, not scattered records.

Deadlines that calculate themselves

Birthdays, renewals, RMD dates, and Medicare-65 eligibility are computed automatically as you view a client — not tracked by hand.

Recurring to-dos

Follow-up tasks generate on a recurring schedule, so nothing depends on remembering to add it to a list.

Product status dashboard

See every client's status across all eight product lines at once, instead of switching between separate screens.

Agent-isolated by default

Database-level row security keeps each agent's book separate — and it's re-verified by an automated test on every single code change, not just at launch.

FAQ

Straight answers

What is this actually built on?▾

It runs on Supabase (Postgres) and Next.js, hosted on Google Cloud Run. It replaced an earlier AppSheet-based version in 2026 — a full rebuild, not a re-skin.

Where is my data stored?▾

In a dedicated Supabase Postgres database — not in your Google Workspace. Each agent's data is isolated at the database level, and every login requires two-factor authentication.

Do you collect Social Security numbers?▾

No. SSN collection was removed from the product — it wasn't needed for how agents actually use client records day to day.

Does it work on mobile and tablet?▾

Yes — it's a responsive web app, so the same interface works in a browser on your phone, tablet, or desktop. There's no separate native app to install.

How many agencies use this today?▾

One, running a real ~2,000-client book in production. We'd rather tell you that plainly than imply a scale we haven't reached yet.
